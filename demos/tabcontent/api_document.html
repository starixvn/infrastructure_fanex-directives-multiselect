Attributes

Attribute Name Type Description
ng-model Array The array that will contain the model for the selected leaf items in the dropdown (The header is based on this data).
all-selected-items Array The array that will contain the model for the selected items in the dropdown.
settings Object The options for the dropdown.
text-settings Object Gives the ability to modify the default texts in the directive.

settings Attribute

Property Type Require Default Value Description
sourceData String / Array / Function x Data that will bind to the dropdown.
idMember String id The property name of data that contains the value used to set the id attribute for each items in dropdown.
nameMember String name The property name of data that contains the value used to display for each items in dropdown.
childrenMember String children The property name of data that contains a list of sub items (if you need multi-level dropdown).
selectedMember String null The property name of data that contains the value you want to retrieve instead of the whole item.
templateUrl String x The url to the dropdown template file.
hasFilter Boolean true Show or hide the filter.
hasToolbar Boolean true Show or hide the toolbar.
collapsedAll Boolean false Default collapsed/expanded state of the tree data.
checkedAll Boolean false Default state of "Check All" check box.
itemFormatter String / Function Provide a way to format items in dropdown. The value can be a function (value, item, level), or a filter name (built-in or custom) such as "uppercase", "lowercase",....
width int 250 Default width of dropdown list in pixel.

text-settings Attribute

Property Default Value
Filter Filter
CheckAll Check all
CollapseExpanse Collapse/Expanse
CollapseBranch Collapse/Expanse this branch
NoItemChecked Select options
ItemsSelected # selected

Events

Event Name Description
ng-change Fired when selecting an item.
ng-on-checkall Fired when checking/unchecking the 'Check All' box.
ng-on-open Fired when the dropdown opens.
ng-on-close Fired when the dropdown closes.
