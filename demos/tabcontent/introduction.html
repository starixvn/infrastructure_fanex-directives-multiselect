Introduction

Angular DropdownTree is an AngularJS UI component (directive) which provides a filter box and hierarchical dropdown.

Supported browsers

Internet Explorer 9+
Firefox
Chrome

Demo

http://10.18.200.209:8586/dropdowntree/index.html

Requirements

- Bootstrap 3 (include Glyphicon)
- AngularJS

Features

- Multi level dropdown item.
- Easy to change text resources.
- Global configuration.
- Custom format item.
- Realtime effect when changing settings, sourcedata,...

Setup

Add two following files to the page you want to use this component (please don't forget the requirement files) 
<link rel="stylesheet" href="directives/fanexdropdowntree/fanex.directive.dropdowntree.css">

<script type="text/javascript" src="directives/fanexdropdowntree/fanex.directive.dropdowntree.min.js"></script>
Download

Usage

// HTML
<dropdowntree class="col-xs-5" 
	ng-model="selectedItems1" 
	settings="settings1""></dropdowntree>
	
// Javascript
var app = angular.module('DemoApp', ['fanex.dropdowntree']);
// ...
 $scope.settings1 = {
	  nameMember: "text",
	  childrenMember: "items",
	  sourceData: data,
	  templateUrl: templateUrl
	};
If you have some dropdowntree with the same settings, you can config them globally: 
// global config
app.config(function(dropdowntreeConfigProvider){
    dropdowntreeConfigProvider.set({
        idMember: "value",
        nameMember: "text",
        childrenMember: "items",
        templateUrl: "dist/fanex.directive.dropdowntree.template.html?v=" + new Date().getTime()        
    });
});
